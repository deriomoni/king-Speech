Это единый промпт для Cursor. Он описывает **весь** уровень «Разогрев»: механику двух заданий, структуру данных, поток и — главное — **визуальный дизайн** под бренд King Speech. Делай строго по этому ТЗ.

## 1. ЧТО ТАКОЕ «РАЗОГРЕВ»

Уровень состоит из **ДВУХ заданий**, игрок проходит их подряд:

1. **ЗАДАНИЕ 1 — Распевка по нотам (pitch-игра).** Игрок поёт распевку (Ми-Мэ-Ма-Мо-Му и др.), ведя голосом светящийся шарик по нотам-ступеням. Высота тона = высота шарика. Тренирует диапазон, интонацию, артикуляцию. **Длительность — минимум 2 минуты.**
2. **ЗАДАНИЕ 2 — Разминка полости рта.** Игрок выполняет артикуляционное упражнение + жест под таймер. **Микрофон не используется, звук не пишется.**

Порядок: сначала Задание 1 (голос) → затем Задание 2 (рот) → переход к следующему уровню модуля.

## 2. ДАННЫЕ — ЕДИНЫЙ ИСТОЧНИК ПРАВДЫ

Весь контент 67 модулей лежит в одном файле: **`king_speech_warmup_content.json`**. Это единственный источник данных уровня. Загружать как статический ассет (`import`/`require`), **не хардкодить** в компонентах.

Получение данных модуля:
```ts
const data = content.find(m => m.module === moduleNumber);
```

Схема одного модуля:
```ts
type WarmupModule = {
  module: number;            // номер модуля 1..67
  rank: 1 | 2 | 3 | 4 | 5;   // ранг (влияет на сложность/коридор)
  sound: string;             // тренируемый согласный модуля, напр. "Р"
  syllables: string[];       // слоги распевки, напр. ["МИ","МЭ","МА","МО","МУ"]
  notes: string[];           // ноты по порядку, напр. ["до","ре","ми","ре","до", ...]
  noteOffsets: number[];     // относительная высота каждой ноты (0 = низ диапазона игрока, 1 = верх)
  repeats: number;           // сколько раз пройти трассу (для набора ≥2 минут)
  task2_mouth: {
    name: string;            // заголовок упражнения
    instruction: string;     // краткая инструкция
    durationSec: number;     // длительность таймера
    gesture: string;         // подсказка жеста
  };
};
```

Важно: высоты нот заданы **относительно** (`noteOffsets` 0..1), а не в абсолютных Гц — это нужно для калибровки под голос конкретного игрока (см. 3.2).

## 3. ЗАДАНИЕ 1 — PITCH GAME (механика)

### 3.1. Определение высоты тона
- С микрофона снимаем основную частоту голоса (Гц) в реальном времени, ~30–60 раз/сек.
- Библиотеки (реально существуют, под Expo/RN): `react-native-pitch-detector` (`{frequency, tone}`), `react-native-pitchy`, либо `@techoptio/react-native-live-pitch-detection`.
- Разрешение на микрофон — `react-native-permissions` (или Expo-аналог), запрашиваем **до** старта уровня.
- Алгоритм: YIN / автокорреляция (устойчив для голоса). **Сглаживание обязательно** (EMA/медиана по 3–5 кадрам), иначе шарик дёргается от микродрожания.

### 3.2. Калибровка под голос (ключевое)
- Один раз на пользователя: ловим низ и верх его комфортного диапазона. Сохраняем в память (AsyncStorage), дальше берём оттуда.
- Шаг 1: «Скажи низко: Мууу» → фиксируем `f_low`. Шаг 2: «Скажи высоко: Миии» → фиксируем `f_high`.
- Дальше `noteOffsets[i]` (0..1) маппится в реальную частоту между `f_low` и `f_high`. Так мужчины/женщины/дети попадают в свои ноты.

### 3.3. Частота → положение шарика (лог-шкала)
- Восприятие высоты логарифмическое, поэтому положение считаем в центах/полутонах, а не в линейных Гц:
  `position = (log2(f_current) − log2(f_low)) / (log2(f_high) − log2(f_low))`, клампим в [0..1].
- `position` → вертикаль шарика (0 = низ трассы, 1 = верх). Движение — пружинное следование (см. дизайн), без рывков.

### 3.4. Коридор попадания (по рангам)
«Прощающий» новичку, строже мастеру:
| Ранг | Допуск | 
|---|---|
| 1 (Новичок) | ±150 центов |
| 2 (Любитель) | ±120 |
| 3 (Уверенный) | ±90 |
| 4 (Мастер) | ±60 |
| 5 (Профи) | ±40 |

Берётся по `data.rank`. Точнее к центру ноты → чище попадание.

### 3.5. Ноты, слоги, длительности, repeats
- Каждая нота из `notes` — ступень на высоте `noteOffsets[i]`. На ступени — цель, которую игрок ведёт голосом.
- **Ширина ступени = длительность ноты:** узкая — короткая нота; широкая — тянуть («сосиска», пройти по ней голосом, удерживая высоту).
- Над ступенями показываем `syllables` — что петь. Слоги идут по кругу (замкнутый ряд).
- Сверху — «Звук: {sound}» (тренируемый согласный модуля).
- `repeats`: трасса проходится столько раз, чтобы суммарно вышло **минимум 2 минуты**. Начало и конец трассы — на одной ноте/слоге (фраза замкнута, плавная петля между повторами).

### 3.6. Сердца и цвета попадания
- **3 сердца** на уровень. Красный промах = −1 сердце. Все 3 разбиты → Задание 1 с начала.
- Состояния попадания:
  | Состояние | Когда | Эффект |
  |---|---|---|
  | Чисто (центр) | точно в центр цели | бонус/комбо, ярче |
  | Касание (край) | в пределах допуска, но с краю | засчитано, без бонуса, сердце НЕ снимается |
  | Промах | выше/ниже допуска, мимо | −1 сердце |

### 3.7. Итог Задания 1
- Звёзды 1–3 по точности (% времени в чистой зоне), показ точности в %.
- Затем переход к Заданию 2.

---

## 4. ЗАДАНИЕ 2 — РАЗМИНКА ПОЛОСТИ РТА (механика)

- Экран берёт `data.task2_mouth`: `name`, `instruction`, `durationSec`, `gesture`.
- Структура: заголовок «Разминка полости рта» → карточка `name` + `instruction` → подсказка жеста `gesture` → длительность → кнопка «Запустить таймер».
- По нажатию: отсчёт 3-2-1 → круговой обратный отсчёт `durationSec` секунд. **Микрофон НЕ используется, звук не пишется.**
- По окончании таймера: галочка + вибрация + кнопка «Далее» → переход к следующему уровню модуля.

---

## 5. ПОЛНЫЙ ПОТОК УРОВНЯ

1. Игрок открывает «Разогрев» модуля N в режиме «Путь».
2. `data = content.find(m => m.module === N)`.
3. Если калибровка голоса не пройдена — показать экран калибровки (один раз, дальше из памяти).
4. **ЗАДАНИЕ 1:** «Звук: {sound}», нотная трасса из `notes`/`noteOffsets` со слогами `syllables`. Отсчёт 3-2-1 → pitch-игра. 3 сердца, цвета попадания, `repeats` до ≥2 минут.
5. Если все сердца разбиты — рестарт Задания 1.
6. Итог Задания 1 (звёзды, точность) → **ЗАДАНИЕ 2** (разминка рта, таймер).
7. По завершении Задания 2 → переход к следующему уровню модуля.

## 6. ДИЗАЙН — «Sonic Minimalism» (сердце этого промпта)

Язык дизайна: **Editorial Typography + Neon Glassmorphism + Brutalist Whitespace**. Метафора фона — «концертный зал, луч прожектора». Тёмная сцена, на ней светится то, что важно. Воздуха много, элементов мало, каждый — заметный.

### 6.0. Токены (использовать строго)
- **Фон:** `#0E0E10` (глубокий тёмный). На активном экране — мягкое радиальное свечение-прожектор за главным элементом.
- **Жёлтый `#FFCF34`** — действие, награда, энергия Оскара. Это **цвет шарика** и всех основных CTA.
- **Фиолетовый `#9468FB`** — **атмосферный**, не кнопочный. Фоновое свечение, частицы «дымки зала», амбиент трассы.
- **Цвет модуля:** берётся из level-палитры (12 тёплых оттенков) по номеру/модулю — им тонируются ноты-ступени конкретного уровня.
- **Палитра рангов** мята→золото — для калибровочной «лестницы голоса» и акцентов прогресса.
- **Шрифты:** Rubik — крупные заголовки и цифры; Nunito — инструкции и UI-текст. Кириллица + казахские глифы обязательны.
- **Мотив:** скруглённый треугольник (зуб короны + волна голоса + тұмар). Используем структурно — как форму нот-ступеней (вершина вверх = «выше тон»), не как наклейку.
- **Орнамент:** қошқар мүйіз — только для праздничных/celebratory моментов (успех, 3 звезды, финиш).
- **Физика анимаций:** пружина с лёгким перелётом (overshoot). Всё «пружинит», ничего не появляется линейно.
- **Карточки:** glassmorphism — блюр (`expo-blur` / BlurView), тонкая светящаяся обводка, низкая непрозрачность заливки.

### 6.1. Экран калибровки — «Поймай свой голос»
- Заголовок Rubik: «Настроим под твой голос». Подзаголовок Nunito — тёплый, ободряющий.
- **Оскар** присутствует как ведущий — в позе «слушаю» (Rive-стейт), реагирует, когда слышит голос.
- Центр — пульсирующая орбита-орб (фиолет→жёлтый), которая **в реальном времени** реагирует на голос: ниже тон → орб ниже/меньше, выше → выше/больше. Это сразу показывает «микрофон тебя слышит».
- Два шага: «Скажи низко: Мууу» (ловим низ) → «Скажи высоко: Миии» (ловим верх). На каждый — пружинный пин-якорь.
- Результат: вертикальная «лестница голоса» с градиентом рангов (мята→золото), подписаны личные низ и верх. Праздничный момент: пружинный pop + росчерк орнамента қошқар мүйіз.
- CTA — жёлтая pill «Готово, поехали».

### 6.2. Pitch Game — главный экран (сцена)
Это герой-экран. Тёмная сцена `#0E0E10`, горизонтальная трасса, луч прожектора за шариком.

- **Трасса.** Ноты-ступени — скруглённые треугольники (мотив зуба короны), вершиной вверх; чем выше нота — тем выше платформа. Каждая тонируется цветом модуля из level-палитры. «Сосиски» (длинные ноты) — широкие платформы, по которым едет шарик; при верном удержании платформа **наливается светом** слева направо.
- **Шарик.** Жёлтый `#FFCF34` светящийся орб (энергия Оскара) с мягким кометным шлейфом. Шарик ВСЕГДА жёлтый — состояние попадания читается **аурой/частицами вокруг него**, а не перекраской (чтобы не конфликтовать с брендовым жёлтым). Следование за голосом — пружинное, «живое».
- **Слог.** Текущий слог — крупно, Rubik, по центру сверху. На смене слога — лёгкий scale-pulse с overshoot. Над ним pill «Звук: {sound}».
- **Сердца.** 3 штуки сверху справа, в брендовой форме (корона/жёлтое сердце). Потеря — пружинное сжатие + обесцвечивание, мягкий haptic.
- **Фидбек попадания (тон — никогда не наказывающий):**
  - *Чисто (центр):* вспышка света + искры (искра в форме қошқар мүйіз как награда), счётчик комбо растёт, прожектор ярче.
  - *Касание (край):* шарик мягко светится, без салюта — спокойное «ок».
  - *Промах:* короткая красная вспышка по краю экрана, лёгкий стопор шарика, разбивается сердце, мягкий haptic. **Без стыда** — Оскар не ругает.
- **Атмосфера.** Фоновые фиолетовые частицы «дымки зала» — низкая непрозрачность, очень медленный дрейф. Прожектор слегка **ярче, когда игрок на ноте** — сцена «дышит» вместе с голосом.
- **Прогресс.** Тонкая линия снизу — путь по 2-минутной трассе. Между `repeats` — плавная петля без обрыва.

### 6.3. Итог Задания 1
- Звёзды 1–3 — появляются по очереди пружинным pop + haptic + звук. Звезда жёлтая.
- Точность % — крупная цифра Rubik, анимированный счётчик (тикает вверх).
- Glassmorphism-карточка результата.
- **Оскар реагирует по результату:** 3 звезды — ликует, корона светится, орнамент қошқар мүйіз обрамляет экран; 1–2 — ободряет («Голос разогревается!»). Любой исход — теплее, чем начался.
- CTA — жёлтая pill «Дальше» → к Заданию 2.

### 6.4. Разминка рта (Задание 2)
- Экран спокойнее — это «фокус», не игра. Меньше эффектов, больше ведения.
- Заголовок Rubik «Разминка полости рта». Glassmorphism-карточка с `name` + `instruction`. Если есть Rive-петля движения рта/жеста — показать её.
- **Сегментный донат-таймер** (наш компонент) — большой круг, считает `durationSec` вниз, кольцо в жёлтом по тёмному фону; в центре — секунды крупно Rubik.
- Подсказка `gesture` снизу — дружелюбной строкой Nunito с иконкой.
- **Нет индикатора записи** — явно показать, что микрофон не используется.
- «Запустить таймер» — жёлтая pill → 3-2-1 → отсчёт. На финише: галочка + пружинный pop + haptic + росчерк қошқар мүйіз, появляется pill «Далее».

### 6.5. Переходы и микроанимации
- Между заданиями и к следующему уровню — пружинный слайд + проход прожектора. Поток бесшовный, с короткой отбивкой «Задание 2 из 2».
- Все появления элементов — пружина с лёгким перелётом. Никаких линейных fade.
- Haptics на ключевых событиях: чистое попадание (light), потеря сердца (medium), финиш (success).

### 6.6. Оскар
- Оскар — ведущий, не надзиратель: уверенный и дружелюбный. Появляется на калибровке, в итогах, на финише. На pitch-игре не мешает геймплею (максимум — реагирует с краю на чистое комбо). Все стейты — через Rive (`@rive-app/react-native`).

### 6.7. Тон (правило)
- Никакого наказания и грусти. Каждый экран заканчивается теплее, чем начался: промах — это «давай ещё», не «ты плохой». Палитра эмоций: лёгкая ирония, ободрение, радость, тепло.
