# Oscar Idle mouth fix (assets/rive/oscar.riv)

The Idle mouth was a closed "lens" of two mismatched curves (fill + 6px
stroke) with looping end handles — it read as a damaged, uneven lip.
`patch.js` reshapes it into the closed smile of the vector "lotus" pose:
a symmetric arc (sag 0.19 of its width), one even round-joined stroke,
keeping the Rive end points so the face proportions stay as designed.

    node patch.js oscar.orig.riv oscar.riv 0.19 0.30 5   # sag, handle, thickness

Only Idle keyframes and base values are touched (float32, in place); the
stroke gets `join = round`. `parse.js` is a generic .riv reader; `defs.json`
(property key → field type) was generated by `defs.js` from rive-runtime's
`include/rive/generated` headers.
