# Kazakh tongue twisters (жаңылтпаштар) — source review

File: assets/content/kk/tonguetwisters_kk.json

Rebuilt 2026-11-20. Every item is now a **folk** жаңылтпаш taken from public Kazakh collections and cross-checked: each item below was found (in the same or nearly the same wording) on **at least two websites**. All previous AI-written (original) items were removed — the verified folk set alone is well above the ~60-item target, so no original was needed.

Verification method: the pages listed under "Sources" were downloaded and each twister was matched clause by clause (≥ 75 % of its clauses had to appear on a page). Where sources disagreed, the majority wording was kept (e.g. «Иір мүйіз сиырды», «шуға апарып шуладым», «Қырық арқарда ақ арқар бар», «Дөңгелек дөннен…»).

Notes for a native-speaker pass:
- Some twisters are archaic or dialectal by nature (шілік, шытырмыш, шырпылылырақ, тайпақбас, шылбыр, қырбық). This is normal for folk жаңылтпаш; drop any that feel too obscure for adult learners.
- bilim-all.kz and erketai.kz publish largely the same list (one likely copied the other). That pair was counted as ONE source for the check: every item below is also attested on at least one other site (ulagat.com, zharar.com, ust.kz, balakai.kz, kk.wikipedia.org or infourok.ru). Items failing that rule would be marked ⚠ — currently none.
- «Жамал Жаңылды…»: the source pages have the typo «жалындырмақшы»; the obvious reading «жаңылдырмақшы» was used.
- The loader takes only the text; daily entries carry `"src": "folk"`.
